# SOC Investigations

This repository documents my hands-on cybersecurity training and SOC analyst practice.

## What You'll Find Here

- Security alert investigations
- SIEM and log analysis
- Splunk and Elastic practice
- Phishing investigations
- Windows and Linux security analysis
- Process-tree analysis
- MITRE ATT&CK mapping
- Incident-response notes

## Goal

I am building practical skills for an entry-level SOC Analyst / Cybersecurity Analyst role while preparing for the CompTIA Security+ certification.

Each investigation will focus on documenting:

1. What triggered the investigation
2. What evidence was reviewed
3. What I discovered
4. How I determined whether activity was malicious or benign
5. What response I would recommend
